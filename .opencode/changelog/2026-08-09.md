# Changes — 2026-08-09

## ATS-first CV restructure + PDF regeneration

- **Why**: The CV rendered to 4 pages on print with a nearly-empty page 1, and the
  only shipped PDF was a 15 MB Photoshop image scan (unparsable by ATS).
  Wanted HTML/PDF semantics that ATS systems parse reliably while keeping the
  same UI and the exact same wording.
- **What**:
  - Self-hosted Inter variable font (`fonts/inter/inter.woff2`) — removed Google
    Fonts CDN dependency so PDF generation is consistent offline.
  - Rebuilt print CSS: A4 page, print-tight spacing, orphan/break control
    (removed blanket `page-break-inside: avoid` on `section` which caused the
    empty page 1). Result: **2 pages A4**, clean break between Datadog/Homarr.
  - Semantics: contact as `<ul>/<li>`; dates wrapped in `<time datetime>`; job
    meta split into `.company` / `.employment-type` / `.location` / `.duration`
    spans; Skills section converted to `<dl>/<dt>/<dd>`; skills separator changed
    from `·` to commas for correct ATS tokenization; lightning-trimmed only the
    summary's third sentence (all wording otherwise untouched).
  - Standard section names (`Experience`, `Skills`, `Education`).
  - Added `<meta name="author">` + schema.org `Person` JSON-LD.
  - Added `scripts/generate-pdf.sh` + `package.json` (`npm run pdf`) and README
    documenting the workflow.
  - Regenerated `assets/cv-thomas-camlong.pdf` (168 KB, text-based, tagged PDF).
  - Cleaned all stale assets: legacy `css/ js/ plugins/`, devicon/unicons fonts,
    obsolete images, `index_fr.html` (old French portfolio), 15 MB PDF.
- **Files**: `index.html`, `assets/cv-thomas-camlong.pdf`, `scripts/generate-pdf.sh`,
  `package.json`, `README.md`, `fonts/inter/` + deletions of legacy assets.
- **Tests/Verification**:
  - `pdfinfo`: 2 pages, A4, title set. `pdftotext`: reading order correct,
    no page furniture, all ATS tokens present (roles, companies, dates, skills).
  - Playwright layout probe: screen UI unchanged (760px, contact single line,
    title-left/dates-right, dl rows aligned).
  - Position-based extraction (bbox) confirmed single-column order — the layout
    used by Textkernel/Sovren/iCIMS-class parsers.
- **Docs**: README updated. No AGENTS.md in repo (global only).
- **Risks**: `index_fr.html` and legacy assets deleted (recoverable via git).
